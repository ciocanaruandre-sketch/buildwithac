# CRM, bucata 4: pagina „Azi” — planul de implementare

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O pagină `/azi`, prima după intrare, care adună tot ce cere o acțiune (De sunat, Discuții, Lucru, Bani), alege cel mai urgent lucru („Acum”) și lasă câteva acțiuni simple direct pe ea.

**Architecture:** Pagina de server citește în paralel din tabelele existente, cu clientul Supabase al omului conectat (RLS-ul rămâne paza banilor și a proiectelor). Un modul pur, `lib/azi.ts`, primește rândurile citite și ora curentă și întoarce lista ordonată, plăcile și cifrele de sus (testat cu vitest, fără bază de date). O componentă client ține tema aleasă, „Mai târziu” și rezultatul apelului; acțiunile refolosesc acțiunile de server existente.

**Tech Stack:** Next.js 16 (App Router, fără cacheComponents), TypeScript, Tailwind, Supabase (`@supabase/ssr`), vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-crm-azi-design.md` (aprobat). Macheta: `prototip/crm-azi.html`, varianta **C · Acum + restul**.

Regulile sunt cele din spec §4, cu rolurile din §6. Ce decide planul, pe lângă spec:
- **Lead nou:** admin = toate; altfel `caller_id === eu || closer_id === eu || caller_id === null`. `urgenta` = `intarziat` dacă `acum − intrat_la ≥ 24h` (cu `la = intrat_la + 24h`), altfel `azi` (cu `la = intrat_la`). `descriere = [ETICHETE.serviciu, ETICHETE.sursa]`, `cand = textIntrat(...)`.
- **Callback:** `stare = 'callback'`, `callback_la` nu e null și e înainte de miezul nopții de după azi (`laOraRomaniei(ziuaPeste(acum,1),"00:00")`); admin = toate, altfel `caller_id === eu || closer_id === eu`. `< acum` → `intarziat`, `cand = "trebuia " + cand(callback_la)`; altfel `azi`, `cand = cand(callback_la)`.
- **Discuție:** `incepe_la ≥ acum − 15 min` și ziua ei e azi sau mâine; non-admin: `closer_id === eu`. `curand = incepe_la ≤ acum + 15 min`. Azi → `azi`, mâine → `urmeaza`; `la = incepe_la`. `descriere = [serviciu]`, iar la admin + `"cu tine"` / `"cu " + prenume`. `href = /lead-uri/<lead_id>`.
- **Task:** `termen` nu e null, `termen ≤ ziuaPeste(acum, 7)`; constructorul: `om_id === eu`; admin: toate, cu ultima bucată din descriere `"tu"`, prenumele omului sau `"neatribuit"`. `nume = titlu` (`numeAscuns: false`), `client = client`, `descriere = [proiect, …]`. `cand`: întârziat → `textIntarziere(zile)`, azi → `"azi"`, mâine → `"mâine"`, altfel `termenScurt(termen)`.
- **Termen:** `inchis_la` null, stadiu în `discutie…revizii`, `termen ≤ azi+7`; constructorul: doar proiectele unde e în `oameniProiect`. `cand`: `"predare depășită cu " + textZile(n)` / `"predare azi"` / `"predare mâine"` / `"predare peste " + textZile(n)`. `descriere = [titlu, ETICHETE.stadiu]`.
- **Cerere nouă** (doar admin): pentru fiecare client cu `lead_id`, cea mai nouă `cereri.primita_la` > cel mai nou `proiecte.creat_la` al clientului. `urgenta: azi`, `la: null`, `cand = cand(primita_la)`, `descriere = ["a trimis iar formularul"]`, `href = /clienti/<id>`.
- **Livrare de refăcut:** `stare = 'de_refacut'`, proiect neînchis; constructorul: doar proiectele lui. `azi`, `la: null`, `cand = "de refăcut"`, `descriere = [titlu livrare, titlu proiect]`.
- **Livrare fără răspuns** (doar admin): `stare = 'trimis'`, `acum − adaugat_la ≥ 5 zile`, proiect neînchis. `urmeaza`, `la = adaugat_la`, `cand = "trimis acum " + textZile(n)`, `telefonNorm` din telefonul clientului.
- **Rată** (doar admin): neîncasată, `tip ≠ 'inainte'`, `scadenta ≤ azi+7`. `< azi` → `intarziat` (`la` = începutul zilei de după scadență), `cand = "întârzie " + textZile(n)`; `= azi` → `azi`, `"azi"`; altfel `urmeaza`, `"mâine"` / `termenScurt`. `nume = client`, `descriere = [eticheta]`, `suma = suma_lei`, `transa = { id, suma: suma_lei }`.
- **Comision** (doar admin): câte unul pe om, din `dePlatitOm(randuri)`, doar când `total > 0 || nestabilite > 0`. `cand_ai_timp`, `suma = total`, `descriere = ["comisioane neplătite"]` + `"N fără sumă încă"` dacă `nestabilite > 0`, `href = /finante`, `comision = { omId, poatePlati }`. Numele omului din echipă nu trece prin `<Ascuns>`.
- **A doua vânzare** (doar admin): data livrării = cel mai recent `stadii.la` cu `in ∈ {livrat, mentenanta}` al proiectului; dacă proiectul e în `livrat`/`mentenanta` fără eveniment, `creat_la`. Rând dacă `30 ≤ zile ≤ 60` și clientul nu are niciun proiect cu `creat_la` > data livrării; câte un rând pe client (livrarea cea mai nouă). `descriere = [LIVRAT[serviciu] + " acum " + săptămâni + " săptămâni", PROPUNERE[serviciu]]`, cu `LIVRAT = { site: "Site livrat", automatizari: "Automatizare livrată", "1la1": "Sesiune ținută", altceva: "Proiect livrat" }`, `PROPUNERE = { site: "propune o automatizare", automatizari: "propune un site", "1la1": "propune ceva nou", altceva: "propune ceva nou" }`, iar săptămânile sunt `Math.floor(zile / 7)`. `cand = "când ai timp"`.
- `textIntrat`: sub 60 min → `"intrat acum N min"` (minimum 1), sub 6 ore → `"intrat acum o oră"` / `"intrat acum N ore"`, altfel `"intrat " + cand(intrat)`.
- `telefonNorm`: lead-uri și discuții din `telefon_norm`; clienți din `normalizeazaTelefon(telefon)`.

Ordinea (spec §5): (1) `curand`, după `la`; (2) `intarziat`, după `la` crescător, la egalitate `lead_nou` primul; (3) `azi`: cele cu `la` după oră, apoi cele cu `la: null`; (4) `urmeaza`, după `la`; (5) `cand_ai_timp`: întâi comisioanele (după nume, `localeCompare(…, "ro")`), apoi vânzările. Sortarea e stabilă.

Numele plăcilor: De sunat, Discuții, Lucru, Bani. `rezumat`: `"N întârziate"` dacă `intarziate > 0` (`"1 întârziată"` la una); altfel, bucățile nenule unite cu `" · "`: sunat `"N noi"` (`"1 nou"`) și `"N callback"`; discuții `"N azi"`, iar dacă sunt 0 azi, `"N mâine"`; lucru `"N task-uri"` (`"1 task"`) și `"N altele"` (`"1 alta"`); bani `"N rate"` (`"1 rată"`), `"N comisioane"` (`"1 comision"`), `"N vânzări"` (`"1 vânzare"`).
